# Jak wnosić zmiany

1. Każda zmiana przez gałąź i pull request do `main`; opis: co, dlaczego, które wiersze rejestru i rozdziały specyfikacji dotyczy.
2. Zmiana modelu = jednocześnie specyfikacja, rejestr założeń, kod i testy.
3. Wartości bez sprawdzonego źródła mają status `robocze`; DOI i liczby z literatury sprawdzane w oryginale.

**Wkłady z zewnątrz:** do czasu przygotowania umowy współtwórcy (decyzja [0006](decyzje/0006-licencje.md)) zmiany wnoszą wyłącznie Piotr i Paweł Mędrzyccy. Uwagi i zgłoszenia (issues) są mile widziane.
