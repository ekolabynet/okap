# Eksperymenty

Format planu (od Okapu Teren 4.0): JSON z polami `name`, `years`, `reps`, `seed0`, `settings` (Q), `experiments` (M); każdy zestaw to nadpisania parametrów `world` i `species`. Równoważnie CSV `typ;nazwa;klucz;wartosc`.

Do ustalenia: biblioteki eksperymentów (katalogi z planem, opisem pytania, hipotezą, wynikami i wersją modelu), skrypty CLI, zapis wyników z sumą kontrolną wejścia.
